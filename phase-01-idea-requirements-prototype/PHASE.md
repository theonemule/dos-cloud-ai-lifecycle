# Phase 1 — Idea, Requirements, Prototype

Status: complete / frozen snapshot

This directory captures the first stage of the conference-demo project.

The work in this phase:
- established the idea
- gathered initial functional and technical requirements
- performed feasibility exploration
- produced a working single-player prototype
- validated the central technical assumption that a DOS game can run against a server-authoritative remote filesystem from an ordinary LAN browser

Do not evolve this directory as the project moves forward. It exists as the presentation snapshot for the end of Phase 1.
